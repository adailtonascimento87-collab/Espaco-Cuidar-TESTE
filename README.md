# 🌿 Espaço Cuidar — Dra. Regiane Barbosa

Plataforma web exclusiva desenvolvida para o **Espaço Cuidar**, combinando fisioterapia clínica e estética de alta performance em Macapá.

---

## 🚀 Funcionalidades Principais

* **Apresentação de Serviços & Terapias:** Catálogo interativo de procedimentos faciais, corporais e fisioterápicos (Hidratação Injetável, Drenagem Linfática, Microagulhamento, Reabilitação, etc.).
* **Simulador de Agendamento:** Formulário integrado para solicitação direta de consultas e pré-agendamento via WhatsApp.
* **Localização e Contato:** Informações completas do estabelecimento no Bairro Universidade com atalho direto para o Google Maps.
* **Painel Administrativo:** Acesso para gestão e atualização de conteúdo.
* **Design Responsivo:** Adaptado para navegação em dispositivos móveis e computadores.

---

## 🛠️ Tecnologias Utilizadas

* **Front-end:** HTML5, CSS3, JavaScript
* **Hospedagem:** GitHub Pages
* **Comunicação:** Integração direta com WhatsApp Web/API
